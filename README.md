# Introduction to Machine Learning — ETH Zurich

Course projects completed as part of **Introduction to Machine Learning** at ETH Zurich in Spring 2024.

The projects cover fundamental machine learning methods ranging from regression and feature engineering to Gaussian processes and neural-network-based image classification.

## Projects

### Task 1a — Ridge Regression
Implementation of ridge regression using the closed-form solution, with 10-fold cross-validation for regularization parameter selection and RMSE evaluation.

### Task 1b — Feature Transformation
Nonlinear feature transformation using linear, quadratic, exponential, and cosine basis functions, followed by regularized linear regression and cross-validation.

### Task 2 — Electricity Price Prediction
Prediction of Swiss electricity prices from heterogeneous tabular data. The pipeline includes missing-value imputation, feature standardization, one-hot encoding, and Gaussian Process Regression.

### Task 3 — Image Similarity Classification
Image similarity classification using pretrained ResNet-18 embeddings and a neural network. Image triplets are transformed into feature representations for binary classification.

## Technologies

Python · NumPy · pandas · scikit-learn · PyTorch · torchvision
